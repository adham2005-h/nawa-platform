# نواة — نموذج واجهة تفاعلي

واجهة عربية RTL لتصور منصة تساعد المطور على إكمال مشروعه ومعاينته وتجهيز نشره وإدارته.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث. لا تحتاج تثبيت أي مكتبات أو تشغيل Backend. يجب أن تبقى بقية الملفات بجانبه.

## جرّب هذه الرحلة

1. افتح مشروع «مكتبتي» ثم تقرير التحليل ومعاينة الواجهة.
2. راجع الخدمة وأكمل الطلب التجريبي. لا توجد دفعات حقيقية أو بيانات بطاقات.
3. نزّل نموذج واجهة HTML من تبويب المعاينة.
4. جرّب محاكاة فشل البناء ثم إعادة المحاولة والنشر التجريبي.
5. أضف مشروعًا من مرجع GitHub أو اسم ملف ZIP. لا يُرفع الملف ولا يُقرأ الكود.
6. عدّل سجلات المنتجات المحلية، ثم جرّب إنشاء نسخة منها واستعادتها.
7. استكشف الفريق والصلاحيات والمساعد ولوحات التطبيقات والتحويل لسطح المكتب.
8. استخدم البحث، وبدّل المظهر، وجرّب الواجهة على هاتف أو نافذة ضيقة.

## حدود النموذج

- هذه واجهة Frontend فقط. تحليل الكود والبناء والنشر والتحويل والمساعد والمدفوعات محاكاة معلّمة بوضوح.
- أمثلة الأسعار والقياسات والقدرات ليست عروض أسعار أو قياسات حقيقية.
- التعديلات تُحفظ في `localStorage` في المتصفح. فتح النسخة من عنوان مختلف قد ينشئ مساحة تجربة مستقلة.
- لا تدخل أسرارًا أو مفاتيح وصول أو بيانات حساسة. لا توجد مصادقة أو صلاحيات Backend.
- لوحة قاعدة البيانات تتعامل مع سجلات نموذجية محلية، والنسخ تحفظ هذه السجلات فقط.
- يمكنك إعادة بيانات العينة من الإعدادات. هذا يمحو تغييرات التجربة المحلية بعد تأكيدك.

## ملفات المصدر

- `index.html`: هيكل الصفحة.
- `styles.css`: التصميم المتجاوب، الوضع الداكن، والتأثيرات.
- `icons.js`: أيقونات SVG محلية.
- `app.js`: رحلة المشاريع والمعاينة والطلب والبناء والنشر والتحويل.
- `secondary.js`: أقسام البيانات والفريق والخدمات والمراقبة والنسخ والمساعد والفوترة والإعدادات.
- `assets/fonts`: خط IBM Plex Sans Arabic مع رخصة OFL المرفقة.

التصميم والرسوم المصغرة والأيقونات لا تحتاج خدمة خارجية. الواجهة لا تجري طلبات API خارجية.


## النشر عبر GitHub Pages

الواجهة جاهزة للنشر كملفات ثابتة من الفرع `main` والمجلد `/ (root)`.
من إعدادات المستودع افتح Pages، واختر Deploy from a branch ثم main ثم /(root).

يبقى المستودع خاصًا. GitHub Pages من المستودعات الخاصة يحتاج خطة حساب مؤهلة مثل GitHub Pro.
لا يُعد العنوان متاحًا حتى تعرض GitHub نجاح عملية النشر.
